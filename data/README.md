# 个人数据库

用 Markdown + 目录组织,可直接阅读、修改,也便于观察 Agent 读了什么、写了什么。

## 目录

- `profile/` — 本人资料(学籍、身份、常用信息)。**敏感,不入 git**。
- `contacts/` — 联系人与组织(导师、辅导员、学院办…),一个文件一个组织或个人。
- `events/` — 活动与通知,按月分文件(`YYYY-MM.md`)。
- `archive/` — 已办事务归档(办完的事、发过的关键邮件摘要)。
- `state/` — 机器状态(索引、已处理邮件 UID),不入 git,勿手改。

## 记录格式

- 每个文件只写一个主题;文件内用 `#` 标题分层。
- 事件记录务必区分三种时间:`活动时间`、`报名截止`、`材料截止`。**截止时间 ≠ 活动开始时间**(用户纠正过的规则)。

## 工具

`py scripts/db.py index|search|show|stats`
