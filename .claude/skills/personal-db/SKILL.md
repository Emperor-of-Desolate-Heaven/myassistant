# 个人数据库

## 何时使用
用户的问题涉及本人资料、日程、联系人、已办事务时,先检索再回答。

## 检索
- 全文检索:`py scripts/db.py search <关键词>`(多个词须全部命中,可用 `-C 3` 扩大上下文)
- 查看条目:`py scripts/db.py show data/xxx.md`
- 索引在资料修改后用 `py scripts/db.py index` 重建

## 引用
回答必须引用出处,格式 `data/xxx.md:行号`。

## 更新
- 新资料:在对应目录建 Markdown 文件(一个文件一个主题,`#` 标题分层)
- 修改:直接编辑文件,然后重建索引
- 事件记录区分 `活动时间` / `报名截止` / `材料截止`;截止时间不是活动开始时间
